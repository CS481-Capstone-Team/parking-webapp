# parking-webapp
Web application for viewing real-time parking availability.

Plain HTML, CSS, and JavaScript. No framework. Vite is the dev server. MSW (Mock Service Worker) fakes the server so the app runs without it.

## Folder structure

```
parking-webapp/
  index.html                  Landing page. Links to Host and Guest.
  host/
    index.html                Host page (HTML). Served at /host/.
  guest/
    index.html                Guest page (HTML). Served at /guest/.
  src/
    host/main.js              Host page JavaScript. Work here.
    guest/main.js             Guest page JavaScript. Work here.
    api.js                    Functions to talk to the server. Use these, never fetch URLs directly.
    style.css                 Shared styles.
  mocks/                      Fake server. Do not edit.
    data.js                   Fake sensors, pools, and events.
    handlers.js               Fake API routes.
    live.js                   Fake live updates and fake cars passing.
    browser.js                Starts the mocks.
    README.md                 Notes on the mocks.
  public/
    mockServiceWorker.js      Generated by MSW. Do not edit.
  vite.config.js              Vite settings.
  package.json                Scripts and dependencies.
  INSTRUCTIONS.md             How to work in this repo.
```

## How it fits together

- HTML file makes the page. `main.js` holds the logic. `src/api.js` gets the data.
- Host and Guest are separate. They share only `src/api.js` and `src/style.css`.
- See `INSTRUCTIONS.md` for details and an example.
